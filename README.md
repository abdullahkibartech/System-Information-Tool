# System-Information-Tool
A Python based system monitoring tool that collects and displays information about a computer's hardware and operating system.

## Features

- Operating system information
- CPU details
- CPU usage percentage
- Physical and logical CPU cores
- Hostname and local IP address
- Python version
- RAM information:
  - Total memory
  - Used memory
  - Available memory
  - Usage percentage
- Disk information:
  - Total storage
  - Used storage
  - Free storage
  - Usage percentage
- Battery information (for supported devices)

## Technologies Used

- Python
- psutil library
- platform module
- socket module
- JSON module
